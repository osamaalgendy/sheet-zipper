# Security policy

Please do not attach sensitive or proprietary workbooks to public issues.

Report suspected vulnerabilities privately to
[support@evernivo.com](mailto:support@evernivo.com?subject=Private%20security%20report).
Include the Sheet Zipper version, operating system, displayed error code, and a
minimal synthetic reproduction when possible.

Public releases are distributed through GitHub Releases and linked from
`download.evernivo.com`. Verify the SHA-256 value published with the release
before investigating a potentially modified installer.
