# Changelog

Release notes are published with each entry on the
[GitHub Releases](https://github.com/osamaalgendy/excel-zipper/releases) page.

## 1.0.0 — release candidate

- Local analysis for XLSX, XLSM, and XLSB workbooks.
- Verified Balanced, Maximum, and Content-aware optimization modes.
- XLZ archival and restoration with integrity verification.
- Multi-file jobs, cancellation, persistent history, and actionable failures.

The public installer remains unavailable until code signing and final release
verification are complete.
